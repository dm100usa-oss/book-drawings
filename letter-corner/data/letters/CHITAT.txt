Здесь 52 буквы, нарезанные из исходных картинок.

Имена: up-A ... up-Z для заглавных, low-a ... low-z для строчных.

Так сделано специально. На компьютерах Apple и Windows имена файлов,
которые различаются только большой и маленькой буквой, считаются
одинаковыми. Если назвать файлы A.json и a.json, то при распаковке
архива из каждой пары уцелеет только один файл, и половина букв пропадёт.

Не переименовывайте обратно.

Строчка в программах, которая делает имя:
    NAME = lambda ch: ('up-' if ch.isupper() else 'low-') + ch

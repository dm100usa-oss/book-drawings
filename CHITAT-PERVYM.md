# Читать первым. Карта репозитория

Здесь лежат две разные серии книг. Не путайте их между собой.

---

## Серия 1. Build a Sentence

Печатные рабочие листы для Teachers Pay Teachers, магазин Magic of Discoveries.
Английская книга готова: 57 страниц, из них 55 рабочих листов.

| Что | Где |
| --- | --- |
| Бриф проекта, читать перед работой | `BRIEF.md` |
| Готовая книга | `Build-a-Sentence-Animals-A-Z.pdf` |
| Буквы для обводки, программы, шрифты букв | `letter-corner/` |
| Сборка книги | `scripts/build_book.py` |
| Шрифты для текста | `fonts/` |
| Новые рисунки Рикардо | `newart/` |

Как собрать книгу заново:

```
python3 scripts/build_book.py
```

Запускать из корня. Готовый файл ляжет в папку `out`.
Рисунки берутся из двух соседних репозиториев, их надо скачать рядом:

```
mkdir repos && cd repos
git clone --depth 1 https://github.com/dm100usa-oss/toddler-coloring-book.git
git clone --depth 1 https://github.com/dm100usa-oss/magic-of-discoveries.git
```

Про буквы читайте `letter-corner/CHITAT-PERVYM.md`. Там правила письма,
что решено и что осталось открытым.

## Правила общения с Рикардо

Только по-русски, коротко, обычными словами, без технических терминов.
Не задавать технических вопросов и не предлагать выбор между техническими
вариантами, решать самому. Не использовать букву е с двумя точками
и длинные тире. Разрешение спрашивать только перед изменением файлов.
Рикардо не читает по-английски и по-испански, весь текст на этих языках
на исполнителе, показывать его не надо.

## Как собрать

Библиотеки: pymupdf, numpy, scikit-image, fontTools, pillow, scipy.
Ставятся через pip с ключом --break-system-packages.

Какую книгу собирать, задается переменной окружения BOOK: 1 или 2.

    cd kod
    BOOK=2 python3 check.py
    BOOK=2 python3 sobrat_knigu.py 0 10 /mnt/user-data/outputs/listy.pdf 3

Первый аргумент - с какого листа, второй - по какой, третий - имя файла,
четвертый - сдвиг номеров. Сдвиг 3 нужен, когда впереди идут страница
учителя и две страницы оглавления.

Вступление и оглавление собираются отдельно:

    BOOK=2 python3 oglavlenie.py /home/claude/nachalo.pdf

Для испанских книг добавляется LANG_BOOK=es. Готовый файл склеивается из
двух: сначала nachalo.pdf, потом листы.
Перед сборкой всегда прогонять check.py. Пустой список замечаний это норма.

Проверка готового листа линейкой:

    python3 proverka_lista.py listy.pdf 1

Должна написать: раскладка совпадает с эталоном полностью.

## Главное правило

Любая правка проверяется дважды: цифрами и глазами.
Правка, которая чинит одну тему и ломает другие, неверная.
Если общее правило не проходит проверку по всем темам, чинить точечно
через списки исключений.

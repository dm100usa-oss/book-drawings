# Сюда кладутся два исходника

Это печатные файлы книг, из которых программа вынимает шаги и фигуры.
Без них ничего собрать нельзя.

Имена должны быть ровно такие:

    book_eng_print.pdf        английский исходник, 231 страница, 111 тем
    book_spanish_print.pdf    испанский исходник, 111 тем

Английский нужен для английских книг, испанский для испанских.
Обе книги устроены одинаково: страница шагов, следом страница с фигурой
для обводки. Темы стоят на одних и тех же номерах страниц.

## Что делать с ними в работе

В kod/build.py есть переменная SRC, там прописан путь к исходнику.
По умолчанию стоит /mnt/user-data/uploads/book_eng_print.pdf.

Если файл берется из этой папки, путь надо поменять на путь к ней.
Для испанских книг там же меняется язык подписей, см. историю правок.

## Чего здесь быть не должно

Картинки страниц. Плоские снимки страниц не годятся: в них линии слиты
в одно изображение, шаги оттуда не вынуть. Нужен именно печатный файл.

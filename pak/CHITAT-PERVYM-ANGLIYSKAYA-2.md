## Как собрать

Списки тем обеих книг уже лежат в build.py: THEMES_1 и THEMES_2.
Какую книгу собирать, задается переменной окружения BOOK.

    cd kod
    BOOK=2 python3 check.py
    BOOK=2 python3 sobrat_knigu.py 0 10 /mnt/user-data/outputs/listy.pdf

Первый аргумент - с какого листа, второй - по какой, третий - имя файла.
Раскладка тем по подложкам уже готова, sobrat_knigu.py, словарь SCENA.

Проверка листа линейкой:

    python3 proverka_lista.py listy.pdf 1

Должна написать: раскладка совпадает с эталоном полностью.

## Как работает заказчик

Его зовут Рикардо. Архитектор, говорит голосом, по-русски, английский
не читает.

- Отвечать только по-русски, простыми словами, без технических терминов.
- Технических вопросов не задавать, решать самому.
- Смотреть каждый собранный лист глазами, а не только запускать программу.
- Собирать по десять листов за раз и каждый раз отдавать ЦЕЛЫЙ файл
  с первого листа, а не только новые десять. Это его прямая просьба.
- Файл отдавать ссылкой на скачивание.
- Ничего не менять сверх того, о чем попросили.
